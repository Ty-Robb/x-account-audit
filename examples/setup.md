# Example: Persistent workspace setup

Invoke explicitly:

```text
Use $setup-x-growth to create ongoing X tracking for @example in this project. My goal is qualified audience growth.
```

Expected result:

- `.x-growth/account.md` stores confirmed strategy and stage;
- `.x-growth/ledger.csv` stores post-level observations after publication;
- `.x-growth/experiments.md` stores controlled questions and decisions;
- `.x-growth/series.md` stores repeatable mechanisms and fatigue status;
- `.x-growth/decisions.md` preserves dated strategic choices;
- `.x-growth/workspace.json` stores schema and review metadata.

A second run skips all existing files. It does not request or store X credentials and does not make persistent state mandatory for public audits.
