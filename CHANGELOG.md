# Changelog

All notable changes are documented here. Versions follow semantic versioning for the suite's public skill and state contracts.

## [Unreleased]

## [0.2.0] - 2026-08-14

### Added

- Four independent stage skills for Day zero, Learning, Repeatability, and Compounding.
- Explicit-only `$setup-x-growth` skill with safe, non-overwriting persistent state.
- Full organic-growth X surface map spanning profiles, formats, discovery, recommendation disclosures, community, analytics, creator tools, accessibility, safety, and automation.
- Daily published-algorithm and weekly official-source monitoring with deduplicated review issues.
- Deterministic suite validator, route/output contracts, unit tests, CI, examples, and release automation.
- Responsive, print-ready HTML audit report template with evidence, cleanup, content, execution, and measurement sections.

### Changed

- Narrowed `$audit-x-account` into the diagnostic router and removed overlapping stage-execution triggers.
- Expanded algorithm interpretation, evidence labels, audit scoring, format guidance, stage gates, regression rules, and safety boundaries.

### Safety

- Source changes require human editorial review; automation never rewrites strategic claims blindly.
- Persistent state excludes credentials, private messages, unnecessary personal data, and unverified metrics.
